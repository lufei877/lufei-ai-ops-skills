# 合集 skill 审核清单（Claude 审 Codex 写的 skill 用）

> v1 · 2026-11-15 · 对照 `AGENTS.md`。每次审核出一张审核单：逐条写 ✅ 通过 / ✏️ 要改（文件:行号 + 怎么改）/ ⛔ 阻塞，最后给结论"可以给路飞实测 / 改完再审"。
> 审核单存在被审仓库的 `reviews/<YYYY-MM-DD>-<skill名>.md`，或直接贴回给路飞。

## A. 底线（任何一条不过 = 阻塞）
- [ ] 搜不到第三方会员包的痕迹：`电商老兵小白`、`jiaowoxiao_bai`、`xiaobai`、`买家五问`、`总控四步`、`调度卡`、`施工图`、`P0/P1/P2 处方`；目录结构和段落不是照它改的。
- [ ] 没有 key、token、账号、真实店铺数据、内部项目名（Dxuanpro、百应选品等）。
- [ ] 示例数据处处标"示例"；没有编出来的销量、转化率、检测、认证。

## B. 结构
- [ ] 分 skill 在 `modules/<编号>-<短名>/`，frontmatter 的 name 和文件夹一致。
- [ ] description 写了"什么时候用"和"不管什么"，用户会说的话能触发。
- [ ] SKILL.md ≤ 150 行，按规范第 6 节的小节写全；入口 SKILL.md 的路由表里加上了它。
- [ ] 没写死某个软件的按钮、菜单、路径。

## C. 档案和提问
- [ ] 开工先读 `店铺资料/` 里的档案；只问缺的；问完写回档案。
- [ ] 一次 ≤ 3 问，给选项；答不上来的记进第 7 栏。
- [ ] 档案存在用户工作目录，不写进 skill 文件夹。

## D. 底座五条
- [ ] 有"做完的标准"3～5 条且能核对，交付前自检。
- [ ] 多步 / 批量 / 动文件的活先出计划等确认。
- [ ] 数字：缺就写缺、标出处、算钱列公式、猜的标推测。
- [ ] 读表先确认口径；去重指标不按天相加；空 ≠ 零。

## E. 输出
- [ ] 分析类出 HTML 报告，顺序：标题区 → 指标卡 → 结论和下一步（≤3 条，先做/本周/观察）→ 图表 → 页脚。
- [ ] 数据用图表不用大段文字；不用饼图 / 3D；图上标关键数。
- [ ] 每张图能分享，导出图右下角和页脚只有"路飞的AI运营笔记"，没有二维码、微信、群、"主页"。
- [ ] 能下载 CSV（带 BOM）；不引用外网资源；390px 宽不横向滚动（截图验证）。
- [ ] 文案类："可直接用"和"说明"分开；卖点注明出自档案哪栏；过了极限词。

## F. 实测证据
- [ ] 附示例输入和跑出来的示例输出；Claude 自己用示例输入再跑一遍（或打开报告截图），结果和描述一致。
- [ ] 报告在桌面宽和手机宽各截一张图放进审核单。

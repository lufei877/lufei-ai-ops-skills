# 抖店主图与 SKU 图构图规范

## 什么时候读
要为宠物商品做主图、SKU 图、变体图，或者统一整套商品图的构图和版式时加载。

## 规则
1. 主图只保留一个核心卖点，默认“一图一结论”；不要把多个卖点堆成说明书。
2. 主图优先保证主体大、干净、清楚，手机端第一眼要能认出商品是什么。
3. 宠物类主图尽量保留“商品与宠物关系”，但不要让宠物抢走商品主角。
4. 主图设计不要默认统一视觉；先抽出可复用的商品底图资产，再开放宠物、场景、卖点、构图、排版去做测试变量。
5. SKU 图必须明确表达规格差异，差异只讲一个维度，避免颜色、尺寸、套餐混在同一张里。
6. 同一套 SKU 图保持同角度、同光线、同裁切、同字体系统，只让差异项变化。
7. 主图文案短而硬，优先写功能词、规格词、场景词，不写长句和解释句；如果是测图阶段，优先生成无字底图，文案后加。
8. 构图输出必须能拆成 prompt 槽位：`主体`、`宠物/场景`、`卖点`、`背景`、`镜头`、`光线`、`文案`、`信任锚点`。

## 主图优先级
1. 商品识别
2. 核心卖点
3. 宠物关系
4. 信任锚点
5. 品牌与风格

## 主图测试变量
1. 宠物按钮
2. 场景按钮
3. 构图按钮
4. 卖点按钮
5. 手势 / 道具按钮
6. 文案按钮

## SKU 图优先级
1. 规格区分
2. 商品识别
3. 统一风格
4. 信息简洁
5. 可批量复制

## 正例
```text
主图：白底，宠物胸背带占画面 60%，左侧一只猫作为使用关系提示，右下角只放“轻盈透气”四个字。
SKU 图：同一角度、同一底色，分别展示 S / M / L 三个尺码，只在图标和文案上切换规格。
```

## 反例
```text
主图里同时出现 3 个卖点、2 个徽章、4 行文案，用户看不出到底卖什么；
SKU 图换了不同背景、不同光线、不同角度，导致整套图像是拼出来的。
```

## 怎么装（WorkBuddy）
1. 点右上角 **Code → Download ZIP** 下载整个仓库，解压（打不开 GitHub 的话，进抖音主页粉丝群领压缩包）
2. 打开 WorkBuddy → 技能 → 上传自己的技能，选要装的那个 skill 文件夹（比如 `skills/marketing-pricing`）
3. 用的时候在输入框打 `/` 选它，或者直接说"用 xxx 技能帮我……"

装了没生效？看任务的执行记录里有没有出现这个技能名，别只信 AI 说"我用了"。

## 用之前看一眼
- 这些 skill 帮你整理资料、出草稿；**改价、上架、回复客户这些动作，你自己确认了再做**。
- 不编数字：skill 里要求 AI 不知道就说不知道。
- 有问题提 Issue，或者进抖音主页粉丝群问。

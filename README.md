# 路飞的AI运营笔记 · 电商运营 Skill 合集

做了 7 年电商运营的路飞，自己写、自己在用的电商 AI skill，免费分享。
WorkBuddy、Claude Code、Codex 都能用。现在只需安装一个 `ecom-ops-collection/` 文件夹，入口会按需求分派到具体模块。

> 每期视频讲一个电商 AI 小技巧，讲到的 skill 都放在这里。抖音、小红书搜「路飞的AI运营笔记」。

## 目录

| 编号 | 模块 | 一句话 | 适合谁 |
|---|---|---|---|
| 01 | [商品营销前分析](ecom-ops-collection/modules/01-marketing-product-analysis) | 上新前确认阶段、买家、问题、价值证据和成交准备度 | 准备上新、换卖法的店主和运营 |
| 02 | [商品定价](ecom-ops-collection/modules/02-marketing-pricing) | 看权益、期限、成本和市场参考，形成可核对的价格方案 | 要定价、调价的 |
| 03 | [抖店主图与 SKU 图构图](ecom-ops-collection/modules/03-douyin-main-sku-image-composition) | 让商品、卖点和规格差异在手机上看清楚 | 做主图和 SKU 图的 |
| 04 | [抖店宠物详情页结构](ecom-ops-collection/modules/04-douyin-detail-page-structure) | 按买家问题安排卖点、图片和证据顺序 | 做详情页的 |
| 05 | [宠物商品图质检](ecom-ops-collection/modules/05-pet-image-quality-review) | 判断主图、SKU 图、详情图保留、改造还是放弃 | 宠物类目 |
| 06 | [宠物商品图片蒸馏](ecom-ops-collection/modules/06-douyin-pet-image-distillation) | 批量拆套图，提炼画面元素、提示词骨架和测试变量 | 宠物类目，进阶 |
| 07 | [营销数据复盘](ecom-ops-collection/modules/07-marketing-data-review) | 复盘发布、咨询、销售、成本数据，找到当前卡点和下一项测试 | 发完内容、上完新要复盘的 |
| 08 | [业务 UI](ecom-ops-collection/modules/08-business-ui) | 设计商品列表、订单表格、投放计划和运营工作台 | 想自己做电商软件的 |
| 09 | [Windows 桌面运营软件架构](ecom-ops-collection/modules/09-desktop-operations-architecture) | 划分 UI、service、worker、队列、数据和迁移边界 | 想自己做电商软件的，进阶 |

## 怎么装

下载或克隆整个仓库，把 `ecom-ops-collection/` 文件夹作为一个合集安装到 Agent 工作区。使用时直接说需求，入口会先检查店铺与商品档案，再分派到对应模块，并说明本次使用了哪个模块。

## 用之前看一眼

- 这些 skill 帮你整理资料、出草稿和报告。改价、上架、回复客户这些动作，你自己确认了再做。
- 不编数字。skill 里要求 Agent 不知道就说不知道，缺数据写暂无。
- 有问题提 Issue，或在抖音私信。

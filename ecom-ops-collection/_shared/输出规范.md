# 输出规范

## 分析类（有数据）

一律输出 HTML 单文件，照 `ecom-ops-collection/_shared/报告模板.html`：

1. 标题区写店铺、时间范围和对比口径，示例数据加“示例数据”标签。
2. 指标卡放 3～5 个指标并带环比。
3. 接着写“结论和下一步”，最多 3 条，按“先做 / 本周 / 观察”分级，每条包含一句结论和一个动作。
4. 再放图表，趋势用折线，构成和排行用横向柱，转化用漏斗，单个数用指标卡，不用饼图和 3D，图上直接标关键数。
5. 每张图带“分享这张图”按钮，导出图片右下角小字只写“路飞的AI运营笔记”，页脚同一行小字。不加二维码、微信号、群或“主页”。
6. 同一份数据支持下载 CSV，CSV 带 BOM，Excel 可以直接打开。
7. 不引用 CDN 或其他外网资源，图表使用内嵌 SVG/JS，390px 宽度不横向滚动。
8. 金额使用 `¥12,860`，比例保留 1～2 位小数，变化使用“+0.22 个百分点”。

## 文案类

- 分开写“可直接用”和“给你看的说明”。
- 每条卖点注明出自档案哪一栏。
- 档案没有证据的卖点不写成肯定句。
- 检查不能说的词、极限词、没有证据的功效和平台禁用词。

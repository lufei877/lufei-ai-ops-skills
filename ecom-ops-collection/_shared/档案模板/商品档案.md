# 商品档案模板（合集底座 · 第 1 块）

> 路飞的AI运营笔记。
> 用法：让 AI 先问你问题，你答完，让它照这个格式整理，存成 `店铺资料/商品档案-<商品名>.md`。以后写标题、详情页、客服回复，先让它读这份档案。商品有变化就说“更新商品档案”。

```
【商品档案】<商品名>　更新：YYYY-MM-DD

1. 卖什么
   - 名称 / 规格 / 价格带：
   - 一句话说清它是什么：

2. 卖给谁
   - 谁买、谁用（不一样就分开写）：
   - 在什么时候、什么地方用：

3. 好在哪（每条后面写证据）
   - 卖点 1：　　　证据：（参数 / 检测报告 / 真实评价原话）
   - 卖点 2：　　　证据：
   - 卖点 3：　　　证据：
   - 跟同类比，最大的不同：

4. 买家最担心什么
   - 差评和问大家里最常见的 3 个问题，以及怎么回答：
   - 买错了、不会用、坏了怎么办（售后怎么承诺）：

5. 不能说的
   - 没证据的功效、极限词（最、第一、顶级）、平台不让说的：

6. 在哪卖、写多长
   - 平台：
   - 标题字数 / 详情页屏数 / 客服回复长度：

7. 我还没想清楚的（AI 问到、我答不上来的，先记在这里）
   -
```

写的时候守住三条：
- 证据栏空着就写“暂无”，不让 AI 补。
- 第 7 条是最值钱的：答不上来的地方，就是详情页最容易写空的地方。
- 一个商品一份档案，店铺通用的信息（店铺定位、发货、售后政策）单独一份店铺档案，所有商品共用。

# 抖店主图与 SKU 图构图

## 什么时候用 / 不管什么

用于规划宠物商品主图、SKU 图和变体图的主体、卖点、规格差异、版式与移动端识别。主图只聚焦一个核心结论，SKU 图只表达一个规格维度。

## 先读

先读店铺档案的类目、定位、不能说的词，再读商品档案的名称、规格、证据、适用对象、场景和平台限制。确认图片任务是主图、SKU 图还是一组变体，缺少商品规格或卖点证据时按提问规范问。

## 步骤

1. 确认图片类型、商品真相、规格差异和移动端使用场景。
2. 为主图确定主体、一个核心卖点、宠物或场景关系、背景、镜头、光线、文案和信任锚点。
3. 为 SKU 图固定角度、光线、裁切、字体和底色，只切换规格项。
4. 先设计可复用的商品底图资产，再把宠物、场景、卖点、构图、道具和文案作为测试变量。
5. 输出主图或 SKU 图的方案，并检查商品识别、信息密度和规格区分。
6. 多张图或动文件前先给计划，完成后逐条自检。

## 做完的标准

- 主图只有一个核心卖点，商品在手机上能一眼识别。
- SKU 图明确写出规格差异，差异项可复核。
- 每套图说明主体、场景、卖点、背景、镜头、光线和文案。
- 视觉判断没有越过档案中的证据边界。
- 已写出移动端检查结论和下一步。

## 输出

输出主图或 SKU 图方案，注明可直接使用的方案和说明，按档案栏位标证据。需要生图时输出可拆分的提示词槽位，不凭视觉猜规格或功效。

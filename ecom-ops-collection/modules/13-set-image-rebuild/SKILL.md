# 套图复刻

版本 v0.2（草稿）· 2026-11-26。

## 什么时候用 / 不管什么

用户给：**参考商品链接** + **自己商品的白底图或实拍图**（可选：规格、卖点、已有商品档案）。
Agent 从链接取出参考图，拆版式，换成用户的商品和文案，出一整套新图，附对照页。

只借版式：每张图放什么信息、文字放哪、商品占多大、画面怎么分区。场景、人物动作、道具、光线为新商品重新设计，文字全部重写。

不管：
- 搬竞品的图、品牌、商标、人物脸、原文案（见 `references/借与不借.md`）。
- 编造检测报告、证书、销量、对比效果。
- 单张修图抠图、视频、没有商品图的"凭空出图"。

## 先读

1. `_shared/底座规则.md`、`_shared/输出规范.md`、`_shared/提问规范.md`。
2. 用户工作目录 `店铺资料/商品档案-<商品名>.md`：第 1 栏规格、第 3 栏卖点和证据、第 5 栏不能说的。有 `10-review-mining` 交接卡就一起读。没有档案不用先建，按第 2 步问缺的，事实来源见 `references/逐图设计卡.md` 的"事实分类"。
3. `references/取图步骤.md`、`references/逐图设计卡.md`、`references/提示词写法.md`、`references/验收与返修.md`。

## 步骤

1. **收材料**：链接、商品图（越多角度越好；有多个规格就每个规格一张）。没有商品图就停下说明原因，不用参考图里的商品凑数。
2. **问缺的**（一次最多 3 个）：商品规格和 SKU 有哪几个、卖点和能证明的资料、要做哪些（默认主图 + SKU + 详情全做）。图上的数字和卖点只来自档案、商品图上看得见的字、用户亲口给的；都没有就用中性场景文案并标 ？待补，不编。
3. **取图**：按 `references/取图步骤.md` 用用户已登录的浏览器打开链接，保存主图、SKU 图、详情图，保留原序号，量真实尺寸。遇验证码或滑块就停，交给用户；取不全或取不到，让用户自己存图给你，不绕过。
4. **整套分析**：数清图数、比例、用途、阅读顺序、色系、文案密度，写成一页总览。
5. **逐图设计卡 + 文案表**：版式锁成文字，每张一卡（格式见 `references/逐图设计卡.md`）。竞品的品牌、优惠、参数不继承；文字块装不下就改文案，不动文字块。
6. **先出计划**（底座规则第 3 条）：把总览、每张图对应哪张参考图和哪几张商品图、先试哪张、做完交什么，打成一页给用户，**确认一次**。之后到交付前不再逐张打断。
7. **先试一张**：挑版式最复杂的，生成、对照检查；通过再做其余，不通过先改规则和提示词。
8. **逐张生成**：一次一张，提示词写法见 `references/提示词写法.md`。每张保存实际提示词、传入的图、工具、版本。
9. **验收返修**：按 `references/验收与返修.md` 逐张检查，先修版式再修局部，改动存新版本；同一处连续两轮修不好就停，查原因，仍不行如实标"未通过"。
10. **交付**：用 `scripts/build_compare.py` 生成对照页，详情图可合成一张长图；写交接卡。完成后逐条自检。

## 做完的标准

- 每张新图都有对应的参考图、设计卡、实际用的提示词和检查结果，能追溯。
- 版式检查逐项有结论（文字块数量和位置、容器类型和数量、商品占比、分区），不是一句"看起来一致"。
- 图里没有竞品的品牌、商标、优惠、参数、人物脸；商品外形、包装、标签、刻度和商品图一致。
- 图上每个数字和卖点都有出处；没出处的没写成肯定句。
- 结果标清楚：通过、带偏差接受（写偏差是什么、谁同意）、未通过（写卡在哪），没有把未通过说成通过。

## 输出

交付目录：

1. `套图对照.html`：单文件，图片以压缩预览嵌在里面，离线能打开，手机 390px 不横向滚动。顶部汇总（几张通过、带偏差、未通过），每张一屏：参考图｜新图｜检查结果｜实际提示词（折叠）。点图放大。由 `scripts/build_compare.py` 生成，用法见 `references/对照页脚本.md`。
2. `图/`：新图最终版，`<序号>-<主图或SKU或详情>.png`；`图/过程/` 放各版本、实际提示词、参考图；详情图合成的长图放 `图/详情长图.png`。
3. `交接卡.md`：做了哪些图、状态、没通过的点、用过的商品图、参考链接。

示例：`references/示例/`（一张主图从设计卡到两轮返修的记录，商品图来自 CC0 图库，卖点和店铺都是示例）。

## 和别的模块

- 卖点不够硬，先跑 `10-review-mining`，再回来做图。
- 只要构图建议、不出图：用 `03`；批量判断保留还是重做：用 `05`；拆一批现成套图找共性：用 `06`。这三个目前写的是抖店宠物类目，通用部分可参考。

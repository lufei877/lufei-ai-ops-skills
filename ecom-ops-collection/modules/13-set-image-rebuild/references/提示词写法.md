# 提示词写法

先看你手里的生图工具一次能传几张图，选对应的写法。

## 写法 A：能同时传参考图和商品图

传入顺序固定：**第 1 张参考图，第 2 张起是商品图**。提示词里写清每张的作用：

```
第 1 张是版式参考，只学它的版式：<版式骨架，照设计卡第一块写>。
第 2、3 张是我的商品，商品的外形、颜色、包装、标签以它们为准，不要改。
新场景：<设计卡第二块>。
文字：<设计卡第三块，逐个文字块写清内容、位置、字数>。
不要出现参考图里的品牌、水印、优惠和人物；不要出现多余的文字。
比例 <……>。
```

## 写法 B：一次只能传一张图

只传**商品图**，把版式用文字完整写进提示词（设计卡第一块就是为这个准备的）：

```
保持这个商品的外形、颜色、包装和标签完全不变。
画面：<分区、商品位置和占比、景别、视角>。
场景：<设计卡第二块>。
文字：<逐个文字块的内容、位置、层级>。
不要品牌标志和水印，不要出现多余的文字。比例 <……>。
```

多个角度的商品图，一次传一张，选和这张图视角最接近的。

## 通用规矩

- 一次一张图，别让工具一次出一整套。
- 版式部分一个字不要省：文字块几个、在哪、多大，写了才能验收。
- 文字内容用引号括起来，逐字写出，工具才会照着画。
- 长文字、参数表、小字容易错：先试直接画；两轮修不对，就让该区域留空白，文字交给用户用修图软件加，在设计卡里标"后期加字"。
- 商品必须以实拍图为准。想让工具"发挥一下"外形的，一律不行。
- 提示词里不写竞品品牌名，也不写"仿 XX 品牌"。

## 返修的写法

每次返修都把三样一起传：**当前这一版、最初的参考图、商品图**，并写明各自的作用。最初的参考图一直是版式依据，不能用上一轮的成图顶替它，否则越修越偏。

```
第 1 张是待修的版本，第 2 张是最初的版式参考，第 3 张是商品图。
只修这些：<哪个文字块或区域、现在的问题、要改成什么>。
已经对的不要动：<列出>。
修完仍以第 2 张的版式为准，不重新设计其他区域。
```

- 只能传一张图的工具：传"当前这一版"，版式要求用文字再写一遍（设计卡第一块）。
- 版式大错（容器类型错、整块缺失）：按设计卡重做这一张，别在错的版式上一点点润色。
- 小字错：定点修，修完把其余区域再看一遍。

## 不要用程序画图顶替

没有用户明确同意，不用代码画、拼、覆盖图片来代替生图工具出图。合成详情长图、做对照页这类"拼接已有图"是允许的。

## 每张要记录的

```
序号 / 版本：
生图工具：
传入的图（按顺序）：
实际提示词（完整原文）：
返回文件：
检查结果：
```

存在 `图/过程/` 里，对照页的"实际提示词"折叠区读它。

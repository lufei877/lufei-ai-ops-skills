# 对照页脚本 build_compare.py

用 Python 3 和 Pillow（`pip install --user pillow`）。读一份 `套图清单.json`，输出一个离线单文件 HTML：图片以压缩预览（宽度最多 1100px）嵌入，原图仍在「图/」目录；新旧图等宽并排，不裁切、不拉伸，点图放大看，顶部汇总三种结果的数量，页脚署名，手机 390px 不横向滚动。也可以把详情图按顺序合成一张长图。

```
python3 scripts/build_compare.py 套图清单.json --out 套图对照.html [--stitch 图/详情长图.png]
```

## 清单格式

```json
{
  "title": "示例商品 套图对照",
  "sample": true,
  "items": [
    {
      "id": "主图2",
      "category": "主图",
      "reference": "参考/主图/主图02.jpg",
      "final": "图/02-主图.png",
      "status": "带偏差接受",
      "issues": ["商品占比约 7/10，比设计卡的 3/5 大"],
      "checks": [["文字块数量、类型、位置", "ok"], ["商品占比", "warn"]],
      "prompt": "实际提示词原文"
    }
  ]
}
```

- `status` 只能是：通过、带偏差接受、未通过、未检查。
- `checks` 每项是 [检查项, ok / warn / bad]；`issues` 写没过的点。
- `reference` 可以留空（没有对应参考图时只显示新图）。
- `sample: true` 时页面上加"示例数据"标签。
- 路径相对清单文件所在目录。图片不存在就在页面上显示"缺图"，不静默跳过。
- 脚本只拼页面，不判断图好不好；检查结果由人或 Agent 看图后写进清单。

# 逐图设计卡

每张参考图写一张卡。目的是把"看起来像"变成可以逐项核对的文字，生图和验收都读它。

## 怎么描述位置和大小

位置用九宫格，从左上到右下：

```
左上  上中  右上
左中  正中  右中
左下  下中  右下
```

大小只分三档，不写像素：

- **大**：占画面宽度或高度一半以上
- **中**：占四分之一到一半
- **小**：不到四分之一

看不清的写"看不清"，不要猜。

## 卡片格式（示例数据，不是真实商品）

```
【设计卡】主图 2 / 共 5
参考图：参考/主图2.jpg　　商品图：商品/正面.jpg、商品/侧面.jpg

一、版式骨架（锁死，不改）
- 画面比例：1:1
- 分区：左 2/3 放商品和场景，右 1/3 放文字
- 商品：位置 正中偏左，大，正面略俯视，占画面高度约 3/5
- 文字块（共 3 个）：
  1. 大标题：右上，两行，粗体，最醒目，约 8 个字
  2. 卖点胶囊：右中，3 个竖排，每个 4～6 个字，圆角底色
  3. 角标：左上，小，圆形，2 个字
- 主副标题大小关系：这张图没有副标题（有的话写"副标题约为主标题的一半高"，每张单独量）
- 容器计数和类型：胶囊 3 个、圆形角标 1 个；若有柱形、卡片、表格、图标矩阵，写清"几个、什么形状、几行几列"，不写"若干"
- 商品展示数量：1 个（参考图展示几个，不等于你卖几个，规格框里写真实规格）
- 留白：商品上方和右下较空
- 色系：暖白底，主色橙，辅色深灰

二、新场景（重新设计，不沿用参考图的场景）
- 场景：<为新商品设计，比如厨房台面、早餐桌>
- 道具：<2～3 样，和商品用途有关>
- 光线：<方向、软硬>
- 人物：<有没有，做什么动作；没有就写"无人物">

三、新文案（每条标出处）
- 大标题：<……>　　出处：商品档案第 3 栏卖点 1
- 胶囊 1～3：<……>　出处：第 3 栏卖点 2、3
- 角标：<……>　　出处：第 1 栏
- 不继承：参考图里的品牌、优惠、参数

四、检查点（验收时逐项看）
- 文字块 3 个，类型和位置对
- 商品占比大、居中偏左
- 商品外形和实拍一致（看盖子形状、把手、颜色）
- 没有竞品品牌残留（看边角）
```

## 写卡的规矩

- 一次先看清整套图的共同点（字体风格、色系、留白习惯），再逐张写，别每张各写各的。
- 文字块要数清：几个、什么类型（标题、胶囊、角标、参数框、对比表）。数量变了就不叫复刻。
- 详情长图不要裁成统一比例，按参考图原来的比例做。
- 某张参考图里的元素你不确定是什么，写"不确定：……"，交给用户判断，不替他决定。

## 文案替换表（每张图一份，逐个文字块填）

| 文字块 | 参考图原文（仅用来看长度） | 新文字 | 出处 | 禁止残留 |
|---|---|---|---|---|
| 大标题 | …… | 宿舍也能用 | 档案第 2 栏 | 竞品品牌名、竞品卖点 |
| 小角标、英文、脚注、规格单位 | …… | 每一个都写替换，没有就写"删除" | | 竞品名、英文品牌 |

大标题换了，边角的小标签、英文、脚注也要逐个换，别只换大字。

## 事实分类（图上的每个数字、卖点都先归类）

1. **商品图上看得见的字**：包装、标签、刻度上写的，以实拍为准，不能改。
2. **用户或档案给的资料**：可以上图，标出处。
3. **试做假设**：只用于试做，用户明确同意才上图，不当成产品事实。
4. **未知**：不上图，标 ？待补，问用户。

参考图里的"证书框、检测报告、百分比对比"是竞品自己的事实：外框形状和位置可以保留，里面不编检测、认证、实验数字，换成真实资料或有出处的生活场景说明。

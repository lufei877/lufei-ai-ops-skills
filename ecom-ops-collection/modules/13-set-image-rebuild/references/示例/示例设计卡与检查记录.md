# 示例：一张主图的完整记录（示例数据）

> 这是示范格式用的。商品是一张免费商用图库里的电水壶照片（CC0，来源：https://www.rawpixel.com/image/6035963/photo-image-public-domain-kitchen-water ），店铺、卖点、证据都是示例，不代表任何真实店铺。
> 这里没放"参考图"：示例的版式是我们自己设定的，不来自任何竞品。真实任务里，参考图在设计卡"参考图"一栏。

## 设计卡

```
【设计卡】主图 2 / 共 5　（示例数据）
商品图：图/商品-示例电水壶.jpg

一、版式骨架（锁死）
- 画面比例：1:1
- 分区：左 2/3 商品和场景，右 1/3 文字
- 商品：正中偏左，大，略俯视，占画面高度约 3/5
- 文字块（共 3 个）：
  1. 大标题：右上，两行，粗体，最醒目
  2. 卖点胶囊：右中，竖排 3 个，圆角橙底
  3. 角标：左上，小，圆形，2 个字
- 色系：暖白底，主色橙，辅色深灰

二、新场景：清晨厨房木台面，一杯茶、半个柠檬，窗边侧逆光；无人物

三、新文案（示例商品档案）
- 大标题「宿舍也能用」　出处：第 2 栏"在什么时候、什么地方用"
- 胶囊「双层防烫」「自动断电」　出处：第 3 栏卖点（示例：说明书写明）
- 胶囊「1.7L容量」　出处：第 1 栏规格；实拍图水位窗最高刻度也是 1.7
- 角标「新品」　出处：第 1 栏

四、检查点
文字块 3 个、类型和位置对；商品占比约 3/5；商品和实拍一致（含水位窗刻度）；无多余文字和装饰线；手机上标题看得清
```

## 第 1 版（图/主图2-v1.jpg）

生图工具的写法：只能传一张图，用"写法 B"（`提示词写法.md`）。传入：商品图。提示词按设计卡四块写。

| 检查项 | 结果 | 说明 |
|---|---|---|
| 文字块数量、类型、位置 | ✅ | 3 个，位置对 |
| 文字内容 | ✅ | 四处文字逐字对，无错字 |
| 额外元素 | ✅ | 没有多余文字和装饰线（上一次试做时标题下面多出了一道橙色线，提示词里加了"不要下划线等装饰线条"后消失） |
| 商品占比 | ✏️ | 约 2/3，比设计卡的 3/5 大 |
| 商品一致 | ⛔ | 水位窗最上面一格刻度被写成 1.5L，实拍是 1.7 |
| 文案 | ⛔ | 胶囊写了 1.5L 容量，和实拍刻度、档案不符（示例里故意放的错：文案要跟档案和实拍走） |

结论：未通过。返修：胶囊改 1.7L；提示词里写明"水位窗刻度保持 1.7 MAX 不变"；写明"占画面高度约 60%，不超过 65%"。

## 第 2 版（图/主图2-v2.jpg）

只改了上面三点，其他提示词不动。三点里改对了两点（刻度、1.7L），占比这一点没改动。

| 检查项 | 结果 | 说明 |
|---|---|---|
| 文字块、文字内容、额外元素 | ✅ | 同第 1 版，数字改成 1.7L |
| 商品一致 | ✅ | 水位窗 1.7 MAX、1.0、0.5 MIN 与实拍一致；红色指示灯、把手形状一致 |
| 商品占比 | ✏️ | 约 7/10，没有变小，反而略大；提示词里写"约 60%、不超过 65%"没起作用 |
| 场景是新的 | ✅ | 台面、茶杯、柠檬都是新设计 |
| 手机可读 | ✅ | 缩到 390 宽，标题和三个胶囊都清楚 |

结论：**带偏差接受**——偏差：商品占比约 7/10，比设计卡的 3/5 大。示例里记为"用户看过同意"。真实任务里，这一条必须真有用户的同意才能这么标。

## 这个例子说明

1. 文字生成得很准，真正容易出事的是**数字、刻度这种"长得像对的"的细节**——所以验收要对着实拍图和档案逐个数字看。
2. 版式描述写得越具体，返修越准；一次只改有问题的几点。
3. 占比这类"大小"要求，只写数字约束不一定管用（本例没起作用）。下一步可以试换成构图说法，如"商品周围留出大片空白"，这个还没试，不要当结论用。
4. "带偏差接受"和"通过"分开记，对照页汇总里分开数。

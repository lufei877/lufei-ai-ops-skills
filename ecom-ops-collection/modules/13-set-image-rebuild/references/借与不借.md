# 借与不借

参考图是学版式用的，不是拿来改个商品就发的。动手前先过这一张。

## 可以借

- 信息分工：第一张放什么、第二张放什么，整套的阅读顺序。
- 版式骨架：文字块的数量、类型、位置、大小关系；商品占画面多大；画面怎么分区。
- 画面语言：景别（远近）、视角、留白多少、色系的冷暖和明暗关系。
- 卖点呈现的"手法"：比如用对比、用局部放大、用数字大字，这些是通用做法。

## 不能借

- 竞品的品牌名、商标、店铺名、水印、角标，一个都不留，包括很小的、边角的。
- 竞品的原图素材：直接拿参考图当底图去改、只换商品不换场景，都不行。场景、人物动作、道具、光线必须重新设计。
- 竞品图里真人的脸和形象。需要人物就重新生成一个，不照着某个人的脸。
- 竞品的文案、优惠、价格、参数、检测结果、证书、销量。这些是竞品自己的事实，不是你的。
- 图案和包装设计：竞品独有的 IP 形象、花纹、专利造型，不复刻。

## 写进图里的话

- 每个数字、每条卖点都要在商品档案里有出处；没有就不写，或标 ？待补等用户补证据。
- 不写"最、第一、顶级"这类极限词，也不写档案第 5 栏列的禁用词。
- 效果对比、前后对比图，只用用户真实拍的；不让 AI 编一张"使用前后"。

## 拿不准时

问用户："这张图里有没有你不确定能不能用的东西？"用户答不上来，就按不借处理。

# 验收与返修

脚本和"看起来差不多"都不算验收。每张图自己对着设计卡的检查点逐项看，写结论。

## 逐项检查（每张都做）

| 项 | 怎么看 | 不过就是 |
|---|---|---|
| 版式：文字块 | 数量、类型、位置、层级和设计卡一致 | 多了、少了、挪了、类型变了（胶囊变成卡片） |
| 版式：分区和占比 | 商品大小、位置、留白和设计卡一致 | 商品变大变小、居中了不该居中 |
| 商品一致 | 和实拍图对照：外形、颜色、包装、标签、Logo 位置 | 盖子、把手、颜色变了；标签乱码 |
| 文字内容 | 一个字一个字对文案；数字对档案 | 错字、乱码、数字不对、多出没写的字 |
| 竞品残留 | 看四个角、边缘、小字 | 有品牌、水印、角标、竞品优惠 |
| 场景是新的 | 和参考图场景对比 | 只是把商品换进竞品的场景 |
| 手机可读 | 缩到 390 宽，主卖点还看得清 | 字太小、商品糊成一团 |
| 整套统一 | 和已通过的几张放一起看 | 色调、字体风格、光线不统一 |

## 返修

1. **先修大的**：版式、商品、文字块问题先修；小字、局部细节后修。
2. **每次改动存新版本**，不覆盖。提示词里只改有问题的那一点，其他不动。
3. **改一处，复查其他**：改完看它有没有带坏已经通过的部分。
4. **同一处连续两轮修不好就停**：不重复同样的操作。检查三件事——传入的图对不对、版式描述有没有自相矛盾、要求是不是超出了工具能力。调整后再做一轮。
5. 还不行：标"未通过"，写清卡在哪、试过什么，交给用户决定。文字类的问题，可以改成留白、后期加字。

## 三种结果

- **通过**：所有检查项都过。
- **带偏差接受**：有不符的地方，但用户看过并同意用。写明偏差是什么、谁同意的。
- **未通过**：有项没过，没有用户的同意。

不把"带偏差接受"和"未通过"写成"通过"。对照页汇总里三种各几张分开数。

## 整套交付前再过一遍

- 所有图放一起：版式规则、色系、字体风格是不是一套。
- 文案之间有没有互相矛盾（这张说 3 档，那张说 4 档）。
- 档案第 5 栏的禁用词，每张图的文字都扫一遍。

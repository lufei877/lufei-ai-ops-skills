# 抖店宠物详情页结构

## 什么时候读
要规划新上架宠物商品的详情页，或者重排现有详情图段落、表达顺序和展现方式时加载。

## 规则
1. 详情页不是图片堆叠，而是销售论证；每一屏只回答一个问题。
2. 顺序先讲“为什么要买”，再讲“为什么是这个”，最后讲“怎么用、怎么买更安心”。
3. 每个段落必须配一种明确视觉方法：`场景图`、`结构图`、`对比图`、`尺寸图`、`步骤图`、`证据图`，不要一屏多种方法混杂。
4. 宠物类详情页必须把 `宠物类型`、`适用阶段`、`尺寸/规格`、`使用方式`、`清洁维护` 讲清楚。
5. 详情页要照顾手机阅读：标题短、段落少、结论先行，避免长篇说明文字。
6. 先做信息骨架，再填图；骨架不清楚时不要直接开始出图。
7. 详情页结尾必须留信任收口：材质、售后、FAQ、真实使用证据，至少占一个段落。

## 推荐段落顺序
1. 首屏总卖点
2. 宠物使用场景
3. 核心功效拆解
4. 材质 / 结构 / 工艺
5. 规格 / 尺寸 / 适配
6. 使用步骤
7. 清洁 / 维护
8. 对比 / 证据 / FAQ

## 正例
```text
第 1 屏：一句话总卖点 + 商品主视觉
第 2 屏：宠物场景图，说明使用痛点
第 3 屏：把核心卖点拆成 3 个小点
第 4 屏：结构细节图，证明材质和工艺
第 5 屏：尺寸图和适配说明
第 6 屏：使用步骤和清洁维护
第 7 屏：FAQ / 售后 / 信任收口
```

## 反例
```text
详情页每一屏都在重复“好用、好看、推荐”，没有推进信息；
尺寸、材质、用法、卖点全挤在一张长图里，手机上无法快速扫读；
把主图风格直接复制到详情页，导致没有论证过程。
```

## 输出契约

交付按论证顺序排列的详情页段落，每段对应卖点、图片与证据；尺寸、适配和使用限制不得由视觉猜测。

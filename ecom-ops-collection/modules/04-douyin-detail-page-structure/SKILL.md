# 抖店宠物详情页结构

## 什么时候用 / 不管什么

用于把宠物商品详情页排成一条能读懂、能核对的销售论证链。每屏只回答一个问题，先做信息骨架，再填图。

## 先读

先读店铺档案的类目、定位、发货售后和不能说的词，再读商品档案的买家、场景、卖点证据、规格、使用方式、清洁维护和常见担忧。缺规格、尺寸、材质或适配证据时按提问规范问，不由图片猜测。

## 步骤

1. 确认商品、宠物类型、适用阶段、规格、使用方式和移动端阅读限制。
2. 先排总卖点、使用场景、核心卖点、材质结构、规格适配、使用步骤、清洁维护和信任收口。
3. 为每个段落指定一种视觉方法，如场景图、结构图、对比图、尺寸图、步骤图或证据图。
4. 每段写清买家问题、结论、图片任务、证据来源和限制。
5. 用简短标题和结论先行的文字检查手机扫读。
6. 多屏或动文件前先给计划，完成后逐条自检。

## 做完的标准

- 段落顺序完整，且每屏只回答一个问题。
- 每个卖点都有档案证据或明确写暂无。
- 尺寸、材质、适配、用法和清洁限制没有靠视觉猜测。
- 结尾包含售后、FAQ、材质或真实使用证据中的信任收口。
- 已检查手机阅读和不能说的词。

## 输出

输出按论证顺序排列的详情页段落。把“可直接用的段落和图片任务”与“给你看的说明”分开，卖点注明商品档案栏目。

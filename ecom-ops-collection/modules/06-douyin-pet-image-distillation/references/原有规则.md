# 抖店宠物类目图片蒸馏

## 什么时候读
做宠物类目商品图蒸馏、批量拆解 40+ 商品套图、总结可复用的生图打法、或为新上架产品输出主图 / SKU 图 / 详情图方案时加载。

## 规则
1. 先按 `主图 / SKU 图 / 详情图` 分桶，再做同类比较；不要把不同任务的图片混在一起评判。
2. 每个商品先补全 6 个基础字段：`宠物类型`、`品类`、`规格/颜色`、`核心功效`、`目标人群`、`使用场景`；缺一项就不能直接下视觉结论。
3. 评价“好图”只看转化相关信号：`一眼看懂卖什么`、`卖点够不够直接`、`看起来是否可信`、`移动端是否清晰`、`是否能区分规格`。
4. 蒸馏时必须拆出 5 层元素：`主体呈现`、`场景/宠物关系`、`卖点表达`、`信任锚点`、`版式与配色`；结论必须能反推成生图 prompt。
5. 给“差图”打标签而不是只写主观感受；只允许使用固定原因，如 `主体不突出`、`卖点不集中`、`信息噪音高`、`宠物关系弱`、`规格表达混乱`、`廉价感强`、`不适合移动端`。
6. 40+ 商品批量跑时，先抽 5 个代表商品建立判断尺，再批量复制字段、统一口径，再逐品修正。
7. 主图蒸馏默认拆成两层：`稳定蒸馏层` 和 `测试变量层`。稳定层只保留商品真相与已验证有效的关系，变量层开放给宠物、场景、构图、卖点、文案、排版去测。
8. 详情页可以统一结构，但主图不要过早统一视觉；主图输出优先做成 `基础底图资产 + 变量按钮`，而不是固定 5 张终稿。
9. 蒸馏结果至少产出 4 类输出：`保留的强元素`、`需要回避的弱元素`、`稳定蒸馏层 prompt 骨架`、`测试变量矩阵`。

## 输出格式
```text
商品：{商品名}
类型：主图 / SKU 图 / 详情图
结论：保留 / 改造 / 放弃
强元素：...
弱元素：...
稳定 prompt 骨架：主体 + 结构 + 颜色/材质 + 使用关系
测试变量：宠物按钮 + 场景按钮 + 卖点按钮 + 构图按钮 + 文案按钮
```

## 正例
```text
商品：宠物胸背带
类型：主图
结论：改造
强元素：主产品清晰、宠物使用关系明确、胸背带结构可见
弱元素：背景太花、文案过长、规格区分不明显
可复用 prompt 骨架：一只猫正在佩戴胸背带，白底或浅色纯背景，突出胸背结构与舒适卖点，移动端一眼看懂
```

## 反例
```text
把宠物零食、窝垫、牵引绳混在同一张图里评审；
只写“好看”“高级”“有感觉”，但说不出主体、卖点和差异；
把详情页长文案硬塞进主图，导致手机端看不清。
```

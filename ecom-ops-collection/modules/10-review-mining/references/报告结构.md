# 报告结构

> v0.1 · 2026-11-20。依据 `_shared/输出规范.md`，HTML 单文件。

## 顺序

1. 标题区：标签（真实数据或示例数据）、版本、商品 id、取数日期、条数。
2. 指标卡（3 到 5 个）：评价条数、差评占比、带图占比、追评差评占比、问大家条数。
3. 结论和下一步：最多 3 条，按「先做 / 本周 / 观察」，每条一句结论加一个动作，动作不夸大。
4. 图表（横向堆叠条，不用 3D）：
   - 好评差评比例（五类）
   - 带图、不带图、有视频的差评率
   - 首评和追评的差评率
   - 规格分布，及各规格好差评比例（样本小于 25 标「样本小」）
   - 按月份评价量和差评
   - 买家夸什么（占非差评条数）
   - 买家骂什么（主题，条数不能相加）
   - 问大家主题
5. 矛盾点表：评价和问大家互相矛盾的地方，写评价编号和问大家编号。
6. 对我们的启示：可以攻 / 必须做到 / 要避开，每条标「依据」和「对我们」，自家没有实测的写 ？待补。
7. 行动包：可直接用 / 给你看的说明 / 待补，写在页面里，不另出 md。
8. 数据说明和附录口径：取到多少、没取到什么、各分类条数相加等于总数；自检记录（抽样复核改了几条、没核验的项）和商品页参数摘录也放这里，不另出 md。
9. 页脚：署名「skill制作by路飞的AI运营笔记」、「转发这个 skill」按钮、版本和更新记录、意见入口、免责一句。

## 规矩

- 每张图有「分享这张图」按钮，导出图右下角只写「路飞的AI运营笔记」。
- 能下载 CSV（带 BOM）。
- 不引用外网资源，手机 390px 不横向滚动，深色模式可读。
- 只放编号，不放买家昵称。
- 转发按钮用页面链接；本地文件链接转发出去别人打不开，要先发布成页面。
- 重复文案、占位好评只标注，不剔除。
- 样例：`真实示例-G153/九阳G153-竞品评价分析.html`。

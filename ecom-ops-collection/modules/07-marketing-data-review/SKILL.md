# 营销数据复盘

## 什么时候用 / 不管什么

用于核对时间窗口、来源、指标口径和可比性，找到当前最需要处理的一环，并定义下一项聚焦测试。缺少发布记录、不可比数据或测量计划时，输出缺口，不宣布赢家。

## 先读

先读店铺档案的类目、定位和价格带，再读商品档案的商品、平台和限制。读取用户提供的发布证据、指标快照、目标、基线、素材和价格版本。分析表格前先把每列的理解、时间范围、分母、去重规则和下单或扣退款口径说给用户确认。

## 步骤

1. 核对每条数据的 ID、时间范围、来源、指标定义、分母、采集时间和去重规则。
2. 对照目标和基线，分开事实、假设、未知和外部因素。
3. 判断当前约束在触达、注意、意向、承接、转化、报价、履约、留存或加购中的哪一环。
4. 检查访客等去重指标没有按天相加，空值没有当零，时间窗口可比。
5. 只保留一个主要变量，写明保留项、新版本、成功指标、时间表和停止条件。
6. 输出 HTML 报告，图表使用共享报告模板；原始快照不覆盖。
7. 多步或动文件前先给计划，完成后逐条自检。

## 做完的标准

- 每个关键指标都有来源、口径、时间范围和分母。
- 事实、假设、未知和外部因素分开。
- 报告顺序符合共享规范，包含指标卡、结论、图表、CSV 和页脚。
- 下一步只有一个主要变量，并写出成功指标和停止条件。
- 数据缺口和置信边界已明确，没有虚构归因。

## 输出

输出单文件 HTML 报告和下一步测试单。报告标示示例数据或真实来源，数字注明文件和列，缺失写暂无。

下一步测试单用人话写清四件事：

- 改什么：只写一个主要变量，以及保留什么。
- 看哪个数：写指标名称、计算口径、数据来源和基线。
- 几天后看：写观察周期和复盘日期。
- 什么情况停：写停止条件、数据不足时的处理和不能下结论的情况。
